# A股量化研究与复现

本仓库用于保存可核验、可复现的量化研究代码，研究环境以聚宽为主。

当前研究主线：

1. 事件驱动因子：SUE、PEAD 与反转效应
2. 分钟线高频选股因子
3. 机器学习驱动的收益预测
4. 多因子 Alpha 研究与策略回测

## 使用原则

- `projects/` 中的每个项目都应能够独立阅读和运行。
- 可复用的代码经过至少两个项目验证后，再移入 `common/`。
- 原始数据、研报原件、提取文本和临时文件不上传 GitHub。
- 每个项目的结论必须包含样本区间、股票池、调仓方式、交易成本和防止未来函数的方法。
